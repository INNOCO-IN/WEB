IN — Design System

One file, two layers: the site's architecture and its design language. Everything renders as the real thing so a designer, a developer, and Claude Design all read identical output. Reference by name — never re-describe a color, a size, or a rule in a prompt again.

How to use this in a build Point Claude Design (or a developer) to a section by number: "Build page per A2 · Detail template, using B3 · Workshop Card and the footer rule in B5." Tokens live once in the :root block at the top of this file — a developer lifts them directly; a designer just names them. Yellow boxes are build instructions. Pink boxes are decisions still open — resolve page-by-page.

B1c

Spacing, grid & shape

Values Base unit 4px. Steps: 8 / 16 / 22 / 26 / 40 / 60 / 80. Gutters: 40px desktop, 20px mobile. Card grid: 4 col desktop / 2 tablet / 1 mobile, 1px hairline gap filled with line (grid lines are visible). Card min-height 300px standard, 420px tall. Corners are square by default (--radius-card: 0) on every tagged content card. Rounded-soft (--radius-soft: 18px) and circles are allowed as a deliberate exception — only on visual-only blocks, avatars, and number/word circles (see B4) — never on a tagged content card. Round is otherwise reserved for the arrow-button and the domain dot.

The spacing scale — pick from these, never in-between

4 · xsinside a chip — icon↔label
8 · smtight stacks — label↔value
16 · mdparagraph↔paragraph
22 · lgcard grid gap
40 · xlheading↔its block · page gutter
80 · 2xlbreathing gap — hero copy↔buttons, buttons↔card wall
120 · 3xlsection↔section — major rhythm break
Vertical rhythm — the one rule Every gap on the page is one of these steps — never a hand-picked number. Three gaps set the whole page's breath: 80px after the hero statement (so the buttons sit low and calm), 80px before the card wall begins, and 120px between any two major sections. Small in-component spacing uses 4–22; anything separating blocks uses 40 / 80 / 120. When in doubt, go one step larger — this system errs generous.
B1d

Signature motif — the MEWE Loop line

A single, organic, hand-drawn line — one continuous surface with one gentle flip (the loop). It carries the MEWE Loop in 2D: SHIFT, kept practicing and moving — each person's shift landing in a different place along the line. It opens the footer and marks major section breaks, and on the live site it draws itself in as you move between pages.

Footer opener — how it sits (seamless)

The Loop line floats on the page ground, with paper continuing beneath it; the footer fill begins lower as a soft tone shift — the line is the only visible division, never a hard straight edge beside it.

Brand marks

Rules The Loop line is the one “loose” gesture against the disciplined grid. It opens the footer and appears at major section breaks — one per break, never inside a card, never decorating text. It replaces the old gradient ribbon entirely — no colored gradient strip anywhere. On the live footer the ribbon inherits the CTA band color and its loop sweeps position per page (see B5).
B2

Card anatomy — the base module

Every card shares one skeleton. Only content and color change. A rotated taxonomy tag + colored dot runs up the left edge (dot lowered to align with the eyebrow); title (Newsreader 700, 30px, line-height 1.0) and description (17px, line-height 1.3) sit beneath; a filled ink round arrow, right-aligned at the bottom means “there’s more inside.” The card link is arrow-only — so the card’s text stays directly editable.

A short description sits beneath it — two or three lines at most.

Required vs optional Required in every card: domain tag (dot + label, reads up the left edge), type tag, title (Newsreader 700, 30px). Optional per type: description (17px, 1–2 lines), medium/role sub-tag, byline, date, arrow (omit only on non-clickable cards, e.g. a pure quote or Experience card). Arrow = filled ink #2E3B40 + paper glyph, no border, right-aligned; link sits on the arrow only. Image boxes default 4:3 (fixed-ratio frame, cover-crop, adjustable per photo). Corners square, always. Backgrounds use warm supporting tints of the page color — no two adjacent cards share a color.

B5

Relational & layout rules

The "don't-make-me-repeat-this" rules. Written once here so no prompt has to restate them.

Footer opening — the rule The footer opens with the MEWE Loop line (B1d) across the full width. The page (paper) ground continues beneath the line; the footer fill (paper-dim) begins below it as a soft tone shift, so the line floats on one continuous ground. No gradient, no colored ribbon, and no hard straight edge beside the line — the Arc line is the only visible division.
Top navigation — compressed mirror of the footer Every page carries a sticky top nav that mirrors the footer in order and destinations (change one, change both). Three category keywords — Start Within · Share the Space · Serve the Whole — each with three dots beneath; Flip Connect is footer-only. IN mark (left) links home; Are you IN? sits apart on the far right as an outline pill (no fill).
• Keywords are labels, not links — the dots are the links.
• Default: small ink dot, no label. Hover: the page name appears as a label, the dot fills its page color, all other dots fade to 30%, and the parent keyword takes the hovered page's color (the other two keywords stay grey). Active page: dot stays filled in its color. Touch: first tap reveals labels, second tap navigates — never unlabeled-and-untappable.
Text never below nav-menu size (13px). Lives in the shared Nav.dc.html; footer lives in Footer.dc.html — keep the two in lock-step.
Home card module — two zones, one rule (CONFIRMED) Every card on the Home grid is the same object: a top zone and a bottom zone. Nothing else varies but size and color.

Top zone — always 4:3, always the card's taxonomy color as its background. Three states, in order of preference:
1 · Photo — a real image fills it. This is the target state for every card.
2 · Color plate — no photo yet, so the taxonomy color shows as a flat plate. This is the default and is never wrong; it reads as "this section, image pending". No stock photos, no illustration stand-ins.
3 · Artwork — a poster or quote card that is itself the content (e.g. Insight). Shown whole, never cropped or scrimmed.

Bottom zone — always paper-dim #F3EAD0 with ink text, on every card without exception. Rail dot = the taxonomy color (the one place the color appears in the bottom zone) — and on the light tones, Story amber #FAB414 and Constellation yellow #F0D23C, the dot carries a 1px ink ring (box-shadow: 0 0 0 1px ink) so it stays visible on paper-dim; every other tone needs no ring. Rail label ink at 60%, eyebrow in the taxonomy color, title Newsreader, one-line description, ink arrow bottom-right.

Why — the color lives in the top zone only, so a card reads as its section at a glance while the type always sits on the same paper. Dropping a photo in replaces a color plate without touching the card's text or layout, and a new card is legible from the moment it exists.

Adding a card — decide four things: which taxonomy (fixes the color and the rail), the size (1×1 default; tall = grid-row: span 2 for portrait artwork; wide for a feature), where it links (an index or a sub-page, never a dead card), and the photo (or accept the color plate). Share the image-slot id with the destination page's key image — key-<section> — so one drop fills the card and the page banner together.

What sits on the Home grid — one card per taxonomy as the standing set (ten), plus feature cards that rotate: the newest News item, the current Story, one Insight. Rotating cards are replaced, not accumulated; the grid stays around a dozen so the page can be read in one screen-and-a-half.
Page-color taxonomy — CONFIRMED AUTHORITATIVE (one color per page; dot order = footer order) Start Within: Manifesto = Teal #1E8A86 · Collectives = Plum #46325A · MEWE = Deep Blue #1E648C.   Share the Space: Workshop = Magenta #E6328C · Story = Amber #FAB414 (INK text) · Protagonist = Orange #F05A28.   Serve the Whole: Project = Slate #1E5A64 · Community = Red #D21E28 · Constellation = Yellow #F0D23C (INK text) · News = Tan #966432.

The page's hero band, nav dot, CTA band, and footer ribbon all use this one color. Navy, Forest, Gold, Green stay in reserve for supporting card tints (Tan is now assigned to News).

Ribbon color — inherits the CTA band (built) The footer ribbon has no fixed color: it inherits the color of the CTA band directly above it via the Footer cta prop, so band + ribbon read as one continuous field with the Möbius loop drawn across it. No CTA → cta="false" → transparent band, loop only. The loop stroke is paper on dark bands, ink on light (amber/yellow). The loop's x-position sweeps left→right across the site journey (Manifesto ~8% … Are-you-IN ~92%) via the Footer loop prop — the walked-line moving further along the path of service per page. Default fails safe to transparent.
Content card spec — the locked module (built) Rotated taxonomy tag + colored dot top-left (dot lowered to align with the eyebrow) → Heading Newsreader 700, 30px, line-height 1.0 → Body 17px, ink, line-height 1.3 → footer circle arrow, right-aligned (FILLED ink #2E3B40 + paper glyph, NO border — one rule everywhere). Growable sets (Collectives, Story, News) built as repeatable patterns; the rest static.

States, accessibility & voice

States Hover: card lifts gently; arrow-button fill inverts (fill ↔ outline). No bounce, no scale, no zoom. Links are teal, sliding toward magenta on hover. Visual-only blocks never move. Focus (keyboard): visible 2px outline in ink (paper on dark cards), 2px offset — never removed. Respect prefers-reduced-motion: disable everything beyond opacity/color.
Contrast Text on dark grounds (plum, deep blue, slate, ink, forest) is always paper (light). Text on bright grounds (amber, yellow, gold) is always ink (dark). Body never below 17px.
Voice (summary — full rules live in the master content file) Calm, direct, humble. "We", not "I". Short sentences. IN in all caps; MEWE as one unit. "Are you IN?" appears exactly twice (Home hero + end of Connect). Every Story ends with a soft "pass it on." Banned sitewide: movement, client, success story, changemaker, profound change, warrior of light, any pricing, the Margaret Mead quote. No emoji.
